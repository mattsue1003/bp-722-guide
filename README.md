## 內容
- 1 分鐘內短影音（9:16，`video/short722.mp4`）
- 血壓計 3 個數字（點一下看說明）
- 血壓紅綠燈＋輸入自己的數字看結果（只在瀏覽器計算，不上傳、不儲存）

- 為什麼會高、偏高怎麼辦、用藥迷思快問快答、看診小抄
