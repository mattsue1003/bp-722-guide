長者社區健康課程用的台語互動簡報，內容與 [blood-pressure-taigi](https://github.com/mattsue1003/blood-pressure-taigi) 相同，只拿掉講師與單一場次的資訊，任何講師、據點都可以直接使用。搭配臉書粉專與 IG「留言關鍵字自動私訊」使用，關鍵字：**722量血壓**。

## 內容（25 頁）
- 先聽大家講、對或不對暖身
- 看懂血壓機 3 個數字、血壓紅綠燈、為什麼會高、一直高會怎樣
- 紙劇場小電影①阿雪姨量血壓（`video/film1.mp4`）、看圖找錯、五句口訣
- 722 原則與紀錄表（可列印空白紀錄表）
- 分類題、排序題、紙劇場小電影②阿坤伯看醫生（`video/film2.mp4`）
- 用藥迷思、四筆帳、六件事、台灣可用資源、大魔王找錯、填空複習、行動承諾、成績單

手機上：左右滑動換頁，上下滑動看完整內容。電腦上：方向鍵換頁、F 全螢幕、N 講師提示。

另附：`guide.html` 一頁式「在家量血壓 722 懶人包」（1 分鐘短影音、紅綠燈自我檢查、可列印 A4 紀錄表）。
